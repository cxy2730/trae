# Reverse Engineering API Skill

This skill enables you to reverse engineer web APIs by:
1. Controlling a browser with HAR recording enabled
2. Analyzing captured network traffic
3. Generating production-ready Python API clients

## Prerequisites

- **Playwright MCP**: You must have access to Playwright MCP tools for browser control
- **HAR Recording**: The browser must be configured to record HAR files
- **Python**: For running analysis scripts and generated clients

## Workflow Overview

```
[User Task] -&gt; [Browser Capture] -&gt; [HAR Analysis] -&gt; [API Client Generation] -&gt; [Testing &amp; Refinement]
```

## Phase 0: Preparation (Using HAR Helper Scripts)

### Available Helper Scripts

This skill provides Python utilities for HAR analysis located at:

**Script Directory:** `plugins/reverse-api-engineer/skills/reverse-engineering-api/scripts/`

**Available Scripts:**
- `har_filter.py` - Filter HAR files to API endpoints only
- `har_analyze.py` - Extract structured endpoint information
- `har_validate.py` - Validate generated code against HAR analysis
- `har_utils.py` - Shared utility functions

### Script Usage Pattern

Use these scripts in sequence for optimal code generation:

```bash
# 1. Filter HAR to remove noise (static assets, analytics, CDN)
python {SKILL_DIR}/scripts/har_filter.py {har_path} --output filtered.har --stats

# 2. Analyze endpoints and extract patterns
python {SKILL_DIR}/scripts/har_analyze.py filtered.har --output analysis.json

# 3. Read analysis for code generation guidance
cat analysis.json

# 4. Generate API client code based on analysis

# 5. Validate generated code
python {SKILL_DIR}/scripts/har_validate.py api_client.py analysis.json
```

### Why Use These Scripts?

**har_filter.py benefits:**
- Reduces HAR file size by 80-90% (removes noise)
- Focuses analysis on actual API calls
- Significantly improves code generation quality
- Outputs statistics showing what was filtered

**har_analyze.py benefits:**
- Provides structured endpoint information
- Detects authentication patterns automatically
- Identifies pagination mechanisms
- Extracts request/response schemas
- Groups endpoints by pattern

**har_validate.py benefits:**
- Ensures all endpoints are implemented
- Validates authentication handling
- Checks for proper error handling
- Calculates coverage score (must be &gt;= 90)
- Identifies missing features

## Phase 2: HAR Analysis

### Reading the HAR File

HAR files are JSON with this structure:
```json
{
  &quot;log&quot;: {
    &quot;entries&quot;: [
      {
        &quot;request&quot;: {
          &quot;method&quot;: &quot;GET|POST|PUT|DELETE&quot;,
          &quot;url&quot;: &quot;https://api.example.com/endpoint&quot;,
          &quot;headers&quot;: [...],
          &quot;postData&quot;: {...}
        },
        &quot;response&quot;: {
          &quot;status&quot;: 200,
          &quot;headers&quot;: [...],
          &quot;content&quot;: {...}
        }
      }
    ]
  }
}
```

### Filtering Relevant Entries

Filter out noise by excluding:
- Static assets: `.js`, `.css`, `.png`, `.jpg`, `.svg`, `.woff`, `.ico`
- Analytics: `google-analytics`, `segment`, `mixpanel`, `hotjar`
- Ads: `doubleclick`, `adsense`, `facebook.com/tr`
- CDN resources: `cloudflare`, `cdn.`, `static.`

Focus on:
- API endpoints: `/api/`, `/v1/`, `/v2/`, `/graphql`
- XHR/Fetch requests with JSON responses
- Requests with authentication headers

### Extracting Patterns

For each relevant endpoint, extract:

1. **URL Pattern**: Base URL, path, query parameters
2. **Method**: GET, POST, PUT, DELETE, PATCH
3. **Headers**: 
   - Required headers (Authorization, Content-Type, custom headers)
   - Optional headers (User-Agent, Accept)
4. **Request Body**: JSON schema, form data structure
5. **Response Schema**: JSON structure, status codes
6. **Authentication**: See [references/AUTH_PATTERNS.md](references/AUTH_PATTERNS.md)

## Phase 3: API Client Generation

### Code Structure

Generate a Python module with:

```
{output_dir}/
  api_client.py    # Main API client class
  README.md        # Usage documentation
```

### api_client.py Template

```python
&quot;&quot;&quot;
Auto-generated API client for {domain}
Generated from HAR capture on {date}
&quot;&quot;&quot;

import requests
from typing import Optional, Dict, Any, List
import logging

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)


class {ClassName}Client:
    &quot;&quot;&quot;API client for {domain}.&quot;&quot;&quot;
    
    def __init__(
        self,
        base_url: str = &quot;{base_url}&quot;,
        session: Optional[requests.Session] = None,
    ):
        self.base_url = base_url.rstrip(&quot;/&quot;)
        self.session = session or requests.Session()
        self._setup_session()
    
    def _setup_session(self):
        &quot;&quot;&quot;Configure session with default headers.&quot;&quot;&quot;
        self.session.headers.update({
            &quot;User-Agent&quot;: &quot;Mozilla/5.0 (compatible)&quot;,
            &quot;Accept&quot;: &quot;application/json&quot;,
            # Add other required headers
        })
    
    def _request(
        self,
        method: str,
        endpoint: str,
        **kwargs,
    ) -&gt; requests.Response:
        &quot;&quot;&quot;Make an HTTP request with error handling.&quot;&quot;&quot;
        url = f&quot;{self.base_url}{endpoint}&quot;
        try:
            response = self.session.request(method, url, **kwargs)
            response.raise_for_status()
            return response
        except requests.exceptions.RequestException as e:
            logger.error(f&quot;Request failed: {e}&quot;)
            raise
    
    # Generated endpoint methods go here
    def get_example(self, param: str) -&gt; Dict[str, Any]:
        &quot;&quot;&quot;
        Fetch example data.
        
        Args:
            param: Description of parameter
            
        Returns:
            JSON response data
        &quot;&quot;&quot;
        response = self._request(&quot;GET&quot;, f&quot;/api/example/{param}&quot;)
        return response.json()


# Example usage
if __name__ == &quot;__main__&quot;:
    client = {ClassName}Client()
    # Example calls
```

### Code Quality Requirements

All generated code must include:

1. **Type hints** for all parameters and return values
2. **Docstrings** for all public methods
3. **Error handling** with try-except blocks
4. **Logging** for debugging
5. **Session management** for connection reuse
6. **Authentication handling** based on detected patterns

## Phase 4: Testing &amp; Refinement

### Testing the Generated Client

After generating the client:

1. Run the example usage section
2. Verify responses match expected structure
3. Handle any errors encountered

### Iteration Protocol

You have up to 5 attempts to fix issues:

```
Attempt 1: Initial implementation
  - What was tried
  - What failed (if anything)
  - What was changed

Attempt 2: Refinement
  ...
```

### Common Issues

| Issue | Solution |
|-------|----------|
| 403 Forbidden | Add missing headers, check authentication |
| Bot detection | Switch to Playwright with stealth mode |
| Rate limiting | Add delays, respect Retry-After headers |
| Session expiry | Implement token refresh logic |
| CORS errors | Use server-side requests (not applicable to Python) |

            // Helper to show/hide root drop zone highlight
            function showRootHighlight() {
                if (rootDropZone) {
                    rootDropZone.style.borderColor = '#818cf8';
                    rootDropZone.style.backgroundColor = '#eef2ff';
                    rootDropZone.textContent = 'Drop here to move to root';
                }
            }

            function hideRootHighlight() {
                if (rootDropZone) {
                    rootDropZone.style.borderColor = 'transparent';
                    rootDropZone.style.backgroundColor = 'transparent';
                    rootDropZone.textContent = '';
                }
            }

            // Make all file items draggable
            fileTree.querySelectorAll('.file-tree-item[data-file-id]').forEach(function(item) {
                item.setAttribute('draggable', 'true');
                item.ondragstart = function(e) {
                    e.dataTransfer.setData('text/plain', item.dataset.fileId);
                    e.dataTransfer.effectAllowed = 'move';
                    item.classList.add('opacity-50');
                    e.stopPropagation();
                    console.log('[Drag] Started dragging file:', item.dataset.fileId);
                };
                item.ondragend = function() {
                    item.classList.remove('opacity-50');
                    document.querySelectorAll('.drag-over').forEach(function(el) { el.classList.remove('drag-over'); });
                    hideRootHighlight();
                };
            });

            // Make folders accept drops
            fileTree.querySelectorAll('[data-folder-id]').forEach(function(folder) {
                folder.ondragover = function(e) {
                    e.preventDefault();
                    e.dataTransfer.dropEffect = 'move';
                    folder.classList.add('drag-over');
                };
                folder.ondragleave = function() { folder.classList.remove('drag-over'); };
                folder.ondrop = function(e) {
                    e.preventDefault();
                    e.stopPropagation();

                            }
                        });
                    }
                };
            });

            if (rootDropZone) {
                rootDropZone.ondragover = function(e) {
                    e.preventDefault();
                    e.stopPropagation();
                    showRootHighlight();
                };

                    hideRootHighlight();
                    var fileId = e.dataTransfer.getData('text/plain');
                    console.log('[Drop] Dropped on file-tree, file:', fileId);
                    moveToRoot(fileId);
                }
            };

        }

        function editorAction(action) {
            const cm = window.cmEditor;
            if (!cm) return;

            const selection = cm.getSelection();
            const actions = {
                'bold': function() { return '**' + (selection || 'bold text') + '**'; },

                'h1': function() { return '# ' + (selection || 'Heading 1'); },

            if (actions[action]) {
                cm.replaceSelection(actions[action]());
                cm.focus();
            }

        function toggleFolder(folderId) {
            const children = document.getElementById('folder-children-' + folderId);
            const arrow = document.getElementById('folder-arrow-' + folderId);

        function applyAiContent(msgId) {
            var btn = document.getElementById('ai-apply-btn-' + msgId);
            if (!btn || btn.disabled) return;

            // Save undo snapshot
            if (window.cmEditor) {
                window._aiUndoContent = window.cmEditor.getValue();
                window._aiUndoMsgId = msgId;
            }

            // State: loading
            btn.disabled = true;
            btn.innerHTML = '<svg class="w-3.5 h-3.5 animate-spin" fill="none" viewBox="0 0 24 24">'
                + '<circle class="opacity-25" cx="12" cy="12" r="10" stroke="currentColor" stroke-width="4"></circle>'
                + '<path class="opacity-75" fill="currentColor" d="M4 12a8 8 0 018-8V0C5.373 0 0 5.373 0 12h4z"></path>'
                + '</svg> Applying\u2026';

            fetch('/workspace/api/ai/content/' + msgId + '/', {
                method: 'POST',
                headers: {'X-CSRFToken': _getCsrfToken(), 'Content-Type': 'application/json'},
            })
            .then(function(res) { return res.json(); })
            .then(function(data) {
                if (data.content && window.cmEditor) {
                    // Use replaceRange to preserve undo history
                    var doc = window.cmEditor.getDoc();
                    var lastLine = doc.lastLine();
                    var lastCh = doc.getLine(lastLine).length;
                    doc.replaceRange(data.content, {line: 0, ch: 0}, {line: lastLine, ch: lastCh});

                    // Trigger auto-save
                    var textarea = document.getElementById('editor-content');
                    if (textarea) {
                        textarea.value = data.content;
                        htmx.trigger(textarea, 'editor-save');
                    }

                    // State: success
                    btn.innerHTML = '<svg class="w-3.5 h-3.5" fill="none" stroke="currentColor" viewBox="0 0 24 24">'
                        + '<path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M5 13l4 4L19 7"></path>'
                        + '</svg> Applied!';
                    btn.className = btn.className.replace('bg-[#18181b]', 'bg-emerald-600').replace('hover:bg-[#27272a]', 'hover:bg-emerald-700');

                    // Show undo button
                    var undoBtn = document.createElement('button');
                    undoBtn.id = 'ai-undo-btn-' + msgId;
                    undoBtn.className = 'text-xs px-3 py-1.5 rounded-lg border border-gray-200 text-gray-700 hover:bg-gray-50 transition-colors';
                    undoBtn.textContent = '\u21A9 Undo';
                    undoBtn.onclick = function() { undoAiApply(msgId); };
                    btn.parentNode.insertBefore(undoBtn, btn.nextSibling);
                }
            })
            .catch(function(err) {
                console.error('Failed to apply AI content:', err);
                // State: reset to idle
                btn.disabled = false;
                btn.innerHTML = '<svg class="w-3.5 h-3.5" fill="none" stroke="currentColor" viewBox="0 0 24 24">'
                    + '<path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M5 13l4 4L19 7"></path>'
                    + '</svg> Apply to Editor';
            });
        }

        function undoAiApply(msgId) {
            if (!window._aiUndoContent || !window.cmEditor) return;

            var doc = window.cmEditor.getDoc();
            var lastLine = doc.lastLine();
            var lastCh = doc.getLine(lastLine).length;
            doc.replaceRange(window._aiUndoContent, {line: 0, ch: 0}, {line: lastLine, ch: lastCh});

            // Trigger auto-save
            var textarea = document.getElementById('editor-content');
            if (textarea) {
                textarea.value = window._aiUndoContent;
                htmx.trigger(textarea, 'editor-save');
            }

            // Reset apply button
            var btn = document.getElementById('ai-apply-btn-' + msgId);
            if (btn) {
                btn.disabled = false;
                btn.className = btn.className.replace('bg-emerald-600', 'bg-[#18181b]').replace('hover:bg-emerald-700', 'hover:bg-[#27272a]');
                btn.innerHTML = '<svg class="w-3.5 h-3.5" fill="none" stroke="currentColor" viewBox="0 0 24 24">'
                    + '<path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M5 13l4 4L19 7"></path>'
                    + '</svg> Apply to Editor';
            }

            // Remove undo button
            var undoBtn = document.getElementById('ai-undo-btn-' + msgId);
            if (undoBtn) undoBtn.remove();

            window._aiUndoContent = null;
            window._aiUndoMsgId = null;
        }

            }, 50);
        });

        // Re-initialize drag and drop when file tree is updated
        document.body.addEventListener('htmx:afterSwap', function(evt) {
            if (evt.detail.target.id === 'file-tree') {
                console.log('[htmx:afterSwap] File tree updated, reinitializing');
                initFileTreeDragDrop();
                restoreExpandedFolders();
            }
        });

        // Global keyboard shortcuts
        document.addEventListener('keydown', function(e) {
            if (e.key === 'Escape') {
                closePreviewModal();
                closeNewFileModal();
            }
        });

        // Click outside to close modals
        document.addEventListener('click', function(e) {
            // Close preview modal
            if (e.target.id === 'preview-modal') {
                closePreviewModal();
            }
            // Close new file modal
            if (e.target.id === 'new-file-modal') {
                closeNewFileModal();
            }
            // Close file menus when clicking outside
            if (!e.target.closest('[id^="file-menu-"]') && !e.target.closest('.file-tree-item button')) {
                document.querySelectorAll('[id^="file-menu-"]').forEach(function(menu) {
                    menu.classList.add('hidden');
                });
            }
        });

        // 搜索下拉框显示控制（桌面端 + 移动端）
        document.body.addEventListener('htmx:afterSwap', function(evt) {
            if (evt.detail.target.id === 'search-dropdown') {
                const dropdown = evt.detail.target;
                const input = document.getElementById('search-input');
                if (dropdown.innerHTML.trim() && input && input.value.length >= 2) {
                    dropdown.classList.remove('hidden');
                } else if (dropdown) {
                    dropdown.classList.add('hidden');
                }
            }
            if (evt.detail.target.id === 'mobile-search-dropdown') {
                const dropdown = evt.detail.target;
                const input = document.getElementById('mobile-search-input');
                if (dropdown.innerHTML.trim() && input && input.value.length >= 2) {
                    dropdown.classList.remove('hidden');
                } else if (dropdown) {
                    dropdown.classList.add('hidden');
                }
            }
        });

        // 点击外部关闭搜索下拉框
        document.addEventListener('click', function(evt) {
            var container = document.getElementById('search-container');
            var dropdown = document.getElementById('search-dropdown');
            if (container && dropdown && !container.contains(evt.target)) {
                dropdown.classList.add('hidden');
            }
            var mobileContainer = document.getElementById('mobile-search-container');
            var mobileDropdown = document.getElementById('mobile-search-dropdown');
            if (mobileContainer && mobileDropdown && !mobileContainer.contains(evt.target)) {
                mobileDropdown.classList.add('hidden');
            }
        });

        // ESC 键关闭搜索下拉框
        document.addEventListener('keydown', function(evt) {
            if (evt.key === 'Escape') {
                var dropdown = document.getElementById('search-dropdown');
                if (dropdown) dropdown.classList.add('hidden');
                var mobileDropdown = document.getElementById('mobile-search-dropdown');
                if (mobileDropdown) mobileDropdown.classList.add('hidden');
            }
        });
    </script>
